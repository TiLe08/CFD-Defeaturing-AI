Was bedeuten die Radien?

Das Tool rollt gedanklich eine Kugel über das Bauteil. Alles, wo die Kugel mit Radius rmax nicht hineinpasst (Bohrungen, Nuten, Gravuren), ist eine Vertiefung. Alles, was eine Kugel mit rvor nicht ausfüllen kann (Schraubenköpfe, Rippen, Schrift), ist ein Vorsprung. rvor muss kleiner sein als die halbe Dicke der dünnsten Wand, sonst wird die Wand selbst zum Feature. Wird ein kleines Feature nicht gefunden, hilft die Genauigkeit „Fein“: das Feature muss etwa zwei Voxel tief sein.
